action grid on
tool box

wait 3
expect snap=Some((GridPoint, 1000, -1000, 0))

wait 3
expect snap=Some((GridPoint, 2000, 1000, 0))
rawp click 1997 1003 0

zoom_extents
wait 5

wait 3

rawp click 1500 0 1997
wait 5

action plugin Beam
wait 5
