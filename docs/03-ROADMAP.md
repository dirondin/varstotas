# Роадмап

## M0 — Каркас (оркестратор) ✅
- workspace, крейты, контракты API, документы.

## M1 — Фундамент (параллельно, 3 потока) ✅
- **Kernel:** Mesh с липкой геометрией (add_line, авто-грани, разбиение рёбер/граней), erase, push_pull, transform_vertices, tessellate, History, save/load, OBJ/STL export, units parser. Тесты.
- **Render:** Camera, Renderer (offscreen MSAA, грани с освещением, front/back цвета, рёбра, толстые/пунктирные оверлеи, сетка, оси, небо/земля, X-ray, wireframe).
- **App shell:** окно, layout в классическом стиле, навигация камерой, тулбар, статус-бар, VCB-виджет, меню файлов, панели (заглушки с реальными данными модели), горячие клавиши.

**Демо M1:** открыть программу, покрутить сцену с тестовым кубом, сохранить/открыть файл.

## M2 — Рисование (2 потока) ✅
- **Tools & Inference:** Select (клик/двойной/тройной/рамки), Line, Rectangle, Circle, Polygon, Arc, Eraser, Push/Pull, Move, Rotate, Offset, Tape Measure + направляющие, Paint Bucket. Inference engine P0. VCB для всех.
- **Kernel:** offset_face, arcs/curves (рёбра, объединённые в кривую), groups (make/explode/edit context), материалы.

**Демо M2:** нарисовать дом из `00-VISION.md`.

## M3 — Полировка MVP ✅ (QA: docs/qa/M3-report.md, docs/qa/M3-round2-report.md)
- Groups edit-контекст, Entity Info, Materials, стили, Zoom Extents, стандартные виды, undo всего, автосохранение.
- QA-проход по UX, исправление багов топологии, производительность (10k+ граней @ 60 FPS).
- Сборка релизов: macOS `.app` (universal), Windows `.exe`.

## M4 — Вторая волна ✅
- **Партия 1:** направляющие как полноценные объекты (выделение, Delete, Move/Rotate/копия, Entity Info, Edit → Delete Guides, скрытие/показ), Tape Measure: resize модели через VCB; Intersect Faces (с моделью / с выделением / с контекстом), Reverse / Orient Faces, Flip Along; Copy / Paste / Paste in Place; экспорт PNG; шаблоны (архитектурный мм/м, дюймы).
- **Партия 2:** Arc (центр + 2 точки), 3 Point Arc, Pie, привязка «касательная в вершине»; Rotated Rectangle; Axes; Dimensions.
  - Доработка (вместе с исправлениями QA партии 2): в диалоге экспорта PNG — выбор, что попадает в картинку: фон/прозрачность (уже есть), оси, направляющие, размеры (dimensions).
  - Dimension: на шаге выноса (смещения) размера сейчас отключены привязки — в перспективе линия с текстом уходит куда угодно, а не в плоскость объекта. Нужно, чтобы при выносе работали все привязки (оси, точки/рёбра/грани объектов, направляющие) и фиксация направления по Shift и стрелкам.
- **Партия 3 ✅:** текстуры (изображения, UV, сохранение в `.vrst`); анимация переходов между сценами.
- Уже сделано раньше: Components + Outliner, Tags, Scenes, Follow Me, Scale, Protractor, импорт OBJ/STL.

## M5 — Дальше ✅
- **Партия 1:** Section Planes ✅ (инструмент, активный разрез, линии и заливка разреза, выбор/Move/Reverse/Align View, видимость в View, состояние в сценах); Soften/Smooth edges ✅; камера: Field of View, Position Camera, Look Around, Walk ✅.
- **Партия 2:** тени (солнце по дате/времени/широте, shadow map), Text (выноски) и 3D Text ✅.
- **Партия 3:** Solid tools (Union/Subtract/Intersect/Trim/Split, Outer Shell), DXF импорт/экспорт ✅.

> **Цель после M5 (решение от 2026-10-14):** действительно рабочий инструмент для хобби-проектов, «без фанатизма». Порядок: M4 → M5 → M6 → M7, поток «Качество» — параллельно. M8 и «Платформы» — только после того, как необходимый функционал на macOS будет полностью готов, и по отдельному решению владельца проекта.

## M6 — Рабочий инструмент ✅
- **Партия 1 ✅:** обмен glTF/GLB (импорт/экспорт), 3MF для 3D-печати; отчёт: спецификация групп/компонентов, размеры для раскроя, площади/объёмы (CSV).
- **Партия 2 ✅:** 2D-документация из модели: виды/разрезы с размерами → экспорт SVG/PDF (облегчённый аналог page layout).
- **Партия 3 ✅:** параметрические компоненты (простые атрибуты: ширина/высота/кол-во).

## M7 — Расширяемость 🟨
- **Партия 1 ✅:** встроенный скриптовый API (Rhai, крейт `varstotas_script`) над ядром; Script Console, File → Run Script…; справочник `docs/SCRIPTING.md`.
- **Партия 2:** MCP-сервер (ниже).
- **Партия 3:** плагины (свои пункты меню и инструменты на скриптах, импортёры/экспортёры) и локальная библиотека компонентов.
- MCP-сервер для ИИ-агентов (Claude Code и др.): инструменты над тем же API, что и скрипты — чтение модели (сущности, размеры, материалы, теги), построение/редактирование геометрии, выделение, камера и скриншот вида, сохранение/экспорт; транспорт stdio + локальный HTTP к запущенному приложению; все изменения агента — через undo (одна операция = один шаг), подтверждение для разрушительных действий.

## Качество (параллельно с M4–M7)
- Устойчивость топологии на больших и «грязных» моделях, точность (f64 до рендера).
- Fuzz-тесты ядра, бенчмарки и clippy/тесты в CI, автообновление приложения.

## Отложено (решение владельца после готовности функционала на macOS)
- **M8 — Визуализация:** PBR, ambient occlusion, мягкие тени, path tracing, экспорт анимации сцен в видео.
- **Платформы:** Linux, веб (WASM + WebGPU), iPad, совместное редактирование.

## Открытые вопросы (решить в будущем)
- Intersect Faces двух групп в пустом пространстве: сейчас создаются только рёбра (грани — только там, где контур лежит в существующей грани). Варианты: оставить или создавать грани из замкнутых плоских контуров (переключатель в `imprint_segments`, `Classify::None` → `Classify::NewEdges`). Решение владельца — позже.
- Релизные бандлы (`.app`/`.exe`) пересобираются только по запросу владельца; для проверки — `target/release/varstotas`.
