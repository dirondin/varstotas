## 7. Measurements box (VCB)
- Ввод без фокуса: просто печатать цифры во время инструмента — P0.
- Единицы: мм / см / м / дюймы / футы (`1'6"`), запятая/точка — P0.
- Повторный ввод корректирует последнюю операцию — P0.
- Массивы `Nx`, `/N`, сегменты `Ns` — P0/P1.
