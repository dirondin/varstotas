# Varstotas — видение продукта

**Varstotas** — лёгкий нативный 3D-редактор (macOS / Windows) классического типа: рисуешь линии — получаются поверхности, тянешь поверхность — получается объём. Никаких деревьев построения, эскизов и ограничений: «карандаш и бумага в 3D».

## Для кого
- Архитекторы, дизайнеры интерьеров, мебельщики, мейкеры — быстрые концепты и простые модели.
- Новички в 3D: инструмент должен быть понятен за 10 минут.

## UX-принципы (не обсуждаются)
1. **Мало инструментов, каждый делает одно дело.** Line, Rectangle, Circle, Push/Pull, Move, Rotate….
2. **Inference everywhere.** Курсор сам «прилипает» к концам, серединам, рёбрам, граням, осям (красная/зелёная/синяя), параллелям и перпендикулярам. Цветные подсказки + всплывающая подпись («Endpoint», «On Red Axis»).
3. **Точность без диалогов.** Measurements box (VCB): после клика просто печатаешь `2500` или `300,200` и жмёшь Enter. Можно исправлять последнюю операцию повторным вводом.
4. **Липкая геометрия.** Рёбра, замкнутые в плоский контур, автоматически образуют грань; линия поперёк грани делит её на две. Группы/компоненты изолируют геометрию.
5. **Всегда подсказка, что делать дальше.** Строка состояния описывает текущий шаг инструмента и модификаторы (Shift — зафиксировать направление, Ctrl/Option — копия, стрелки — фиксация оси).
6. **Мгновенный отклик.** 60+ FPS на сценах в десятки тысяч граней, запуск < 1 c, бинарь < 30 МБ.
7. **Неограниченный Undo/Redo** для каждой операции.

## Что НЕ делаем (на старте)
- Совместимость с закрытыми форматами других программ — только свой формат `.vrst` + экспорт/импорт OBJ/STL.
- Ruby API / extension store, page layout, фотореалистичный рендер, облако.

## Критерии успеха MVP
Пользователь без инструкции рисует дом: прямоугольник пола → Push/Pull стен → линии крыши → Move вершины конька → окна через Offset + Push/Pull, окрашивает материалами, сохраняет и экспортирует в OBJ.
