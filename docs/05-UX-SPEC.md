## Горячие клавиши
Space Select · L Line · A Arc · R Rectangle · C Circle · E Eraser · B Paint · P Push/Pull · M Move · Q Rotate · S Scale · F Offset · T Tape · O Orbit · H Pan · Z Zoom · Shift+Z Zoom Extents · G Make Group/Component · Ctrl/Cmd+Z/Y undo/redo · Delete — удалить выделение · Esc — отмена шага · Ctrl/Cmd+A — выделить всё · Ctrl/Cmd+S/O/N.
Средняя кнопка — Orbit, Shift+средняя — Pan, колесо — Zoom к курсору (в любом инструменте). На трекпаде Mac: два пальца — orbit, Shift+два пальца — pan, pinch — zoom.

## Measurements box (VCB)
- Пока инструмент активен, ввод цифр с клавиатуры **без клика в поле** попадает в VCB. Enter — применить.
- Метка поля меняется по инструменту: Length, Dimensions, Radius, Sides, Distance, Angle, Scale, Offset.
- Значения: `2500` (в единицах модели), `250cm`, `2.5m`, `10'`, `6"`, `1'6"`; пара `300;200` или `300,200` (если десятичный разделитель — точка).
- После завершения операции новый ввод правит последнюю операцию (длину линии, глубину push/pull, радиус…).
- Массивы после Move/Rotate-копии: `5x` (ещё 5 копий на том же шаге), `/5` (5 копий в интервале).
- Окружность/полигон: `24s` — число сегментов/сторон.

## Inference (привязки)
Приоритет: Endpoint > Midpoint/Center > Intersection > On Edge > axis/parallel/perpendicular направления > On Face > свободная точка.
Радиус захвата: 12 px (точки), 8 px (рёбра). Подсказка-тултип рядом с курсором (с задержкой ~150 мс).
| Тип | Маркер | Цвет |
|---|---|---|
| Endpoint | круг ● | зелёный `#00C000` |
| Midpoint | круг ● | голубой `#00C0FF` |
| On Edge | квадрат ■ | красный `#FF0000` |
| On Face | ромб ◆ | синий `#0000FF` |
| Center | круг ◯ | зелёный |
| Intersection | крест ✕ | красный |
| On Red/Green/Blue Axis | линия | красная/зелёная/синяя |
| Parallel/Perpendicular to Edge | линия | пурпурная `#FF00FF` |
| From Point | пунктир | цвет оси |
- **Shift** удерживает текущую привязку направления/плоскости.
- **Стрелки:** → фиксировать красную ось, ← зелёную, ↑ синюю, ↓ параллель/перпендикуляр к ребру под курсором.
- Наведение на точку (~0.5 с) делает её «опорной»: от неё строятся пунктирные оси (From Point).

## Инструменты (шаги)
- **Line:** клик A → [движение: резиновая линия + VCB Length] → клик B (B становится началом следующей) … Esc/двойной клик — конец. Замкнутый плоский контур → грань.
- **Rectangle:** клик угол 1 → движение (плоскость: грань под курсором, иначе плоскость земли/оси по направлению взгляда) → клик угол 2. VCB `w,h`. Inference квадрата («Square») и золотого сечения.
- **Circle/Polygon:** клик центр (ориентация — по грани под курсором, иначе горизонтально) → клик радиус. VCB: перед первым кликом — `Ns` сегментов; после — радиус. Default 24 сегмента / 6 сторон.
- **Arc (2pt):** клик начало → клик конец → движение выпуклости → клик. Привязка «Half circle», «Tangent».
- **Push/Pull:** наведение подсвечивает грань → клик → движение (дистанция по нормали) → клик. VCB Distance. Двойной клик — повтор прошлой дистанции. Ctrl/Option — оставить исходную грань. Вдавливание сквозь объект до противоположной параллельной грани — сквозное отверстие.
- **Move:** если есть выделение — двигаем его; иначе — объект под курсором (подсвечивается). Клик точки захвата → клик назначения. Ctrl/Option — копия. Перемещение вершин/рёбер/граней растягивает связанную геометрию. Стрелки фиксируют ось.
- **Rotate:** клик — центр (транспортир ориентируется по грани / по оси стрелкой) → клик — нулевое направление → клик — угол (шаг привязки 15°). VCB Angle.
- **Offset:** клик по грани → движение внутрь/наружу → клик. VCB Distance. Двойной клик — повтор.
- **Eraser:** клик/протягивание по рёбрам; удаление ребра удаляет примыкающие грани.
- **Tape Measure:** клик → клик: показывает расстояние; с Ctrl (по умолчанию включено) от ребра — направляющая параллельная линия, от точки — guide point.
- **Paint Bucket:** клик по грани — материал из панели Materials; Alt/Option — пипетка; Ctrl — все связные грани; Shift — все грани с тем же материалом.
- **Select:** клик — сущность; двойной клик по грани — грань + её рёбра; тройной — всё связное; рамка слева-направо — только целиком попавшие, справа-налево — пересекающие. Ctrl — добавить, Shift — переключить, Ctrl+Shift — убрать. Двойной клик по группе — вход в редактирование; Esc / клик вне — выход.
