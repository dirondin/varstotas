# Скрипты (Rhai)

Varstotas встраивает язык [Rhai](https://rhai.rs/book/) — простой скриптовый язык с синтаксисом, похожим на Rust/JavaScript. Где запускать:

- **Window → Script Console** — редактор и лог вывода. Cmd+Enter — выполнить, Cmd+↑/↓ — история, Open…/Save… — файлы `.rhai`. Текст редактора сохраняется между запусками.
  - Редактор подсвечивает синтаксис (ключевые слова, функции API, константы, строки, числа, комментарии — тёмно-зелёные) и нумерует строки.
  - **Автодополнение** — по мере ввода: функции API, ключевые слова, `ORIGIN/X/Y/Z` и слова из самого скрипта. ↑/↓ — выбор, Tab — вставить, Esc — скрыть.
  - **Свойства и методы после точки** — по типу того, что слева: `let g = box(…)` → у `g.` есть `name`, `definition`, `material`…; `let f = rect(…)` → `area`, `normal`, `edges`…; `for e in edges()` → свойства ребра; `f.normal.` и `points[0].` → `x`, `y`, `z`, `dot(b)`, `distance(b)`…; у массивов — `len()`, `filter(…)`, у `bounds(x)` — `min`, `max`, `size`, `center`. Тип неизвестен — показываются свойства всех сущностей. В списке видны тип результата и описание; ↑/↓, Tab или Enter — вставить (методы — со скобкой), Esc — скрыть.
  - **Заголовок скрипта:** строки `// @tag …` подсвечиваются (тег — как ключевое слово, дальше строки, числа, `true`/`false`, тип после `:`). После `// @` список тегов (`@name`, `@menu`, `@description`, `@param`, `@pick`, `@select`, `@import`, `@export`) с синтаксисом, после `// @param key:` — типы (`length`, `int`, `number`, `text`, `bool`); пока курсор в строке тега, над ней виден её синтаксис.
  - **Переменные из заголовка** — ключи `@param`, `points` (при `@pick`), `objects` (при `@select`), `path` (при `@import` / `@export`) — выделены тёмно-бирюзовым цветом, чтобы их было видно среди обычных переменных, и предлагаются в автодополнении; их тип известен дополнению после точки (`points[0].` → `x`, `distance(b)`…).
  - **Подсказка параметров**: внутри вызова (`box(ORIGIN, 10, |`) над курсором показывается сигнатура функции, текущий аргумент подчёркнут, справа — короткое описание. Сигнатуры — `varstotas_script::help`.
  - Полоску между логом и редактором можно тянуть: редактор становится выше или ниже; окно тоже растягивается.
  - **Параметры как у плагинов:** если код начинается с заголовка `// @param …`, `// @pick N "…"` или `// @select "…"` (см. `docs/PLUGINS.md`), Run сначала открывает диалог параметров, затем просит кликнуть точки и выбрать объекты, и только потом выполняет код (один шаг Undo, «Script» или `@name`).
- **File → Run Script…** — выполнить файл `.rhai`. Пример — `examples/scripts/bookshelf.rhai`.

Правила:
- Один запуск — **один шаг Undo** («Script»). Если скрипт упал с ошибкой, модель не меняется. В лог пишется сообщение со строкой и позицией.
- Координаты **мировые, в миллиметрах**. Числа можно писать целыми (`1000`) или дробными; длины — строкой с единицами: `"1.2m"`, `"30cm"`, `"6\""`.
- Новая геометрия создаётся в **текущем контексте**: открытая группа в момент запуска, или та, в которую вошли через `enter(g)`.
- Скрипт останавливается через 30 секунд работы (бесконечный цикл не повесит приложение).
- `print(x)` пишет в лог. Значение последнего выражения тоже выводится.
- Строковые методы Rhai `trim()`, `to_upper()` и подобные меняют строку на месте и возвращают `()`: пишите `s.trim(); if s == "" { … }`.
- Плагины (свои пункты меню, диалоги параметров, выбор точек, импортёры и экспортёры) описаны в `docs/PLUGINS.md`.

Сущности (грани, рёбра, группы) — это «ссылки». После операций, которые сливают или режут геометрию (новая грань поверх старой, Push/Pull насквозь), старая ссылка может стать недействительной. Проверить — `e.valid`; при обращении к такой ссылке будет понятная ошибка.

## Векторы
| Запись | Смысл |
|---|---|
| `vec3(x, y, z)`, `vec3(x, y)`, `[x, y, z]` | точка / вектор (массив тоже принимается везде, где нужна точка) |
| `ORIGIN`, `X`, `Y`, `Z` | начало координат и единичные оси |
| `a + b`, `a - b`, `a * k`, `k * a`, `a / k`, `-a` | арифметика |
| `v.x`, `v.y`, `v.z` | компоненты (можно присваивать) |
| `v.length()`, `v.normalize()`, `a.dot(b)`, `a.cross(b)`, `a.distance(b)` | |
| `length("2.5m")` | разобрать длину с единицами → мм |

## Построение
| Функция | Результат |
|---|---|
| `line(a, b)` | массив рёбер |
| `polyline([p1, p2, …])`, `polyline(pts, true)` | рёбра (замкнутая — с гранью, если плоская; лежащая грань смотрит вверх) |
| `face([p1, p2, p3, …])` | грань (лежащая горизонтально свободная грань смотрит вверх) |
| `rect(origin, w, d)` | прямоугольная грань в плоскости XY |
| `circle(center, r)`, `circle(center, r, segments)`, `circle(center, r, segments, normal)` | грань круга (или рёбра, если грань не образовалась) |
| `polygon(center, r, sides)`, `polygon(center, r, sides, normal)` | грань многоугольника |
| `arc(center, start_point, degrees)`, `…, segments)`, `…, segments, normal)` | рёбра дуги |
| `box(origin, sx, sy, sz)` | новая **группа**-параллелепипед (минимальный угол — `origin`; отрицательные размеры откладываются в другую сторону) |
| `cylinder(center, r, h)`, `cylinder(center, r, h, segments)` | новая группа-цилиндр (низ в `center`) |
| `dimension(a, b, offset)` | линейный размер между точками, вынос — вектор `offset` |
| `note(at, offset, "text")` | текстовая выноска |

## Операции
| Функция | Результат |
|---|---|
| `pushpull(face, d)` | грань-«крышка» (d > 0 — по нормали) |
| `offset(face, d)` | новая внутренняя (d < 0) или внешняя грань |
| `follow_me(face, edges)` | протяжка профиля по пути |
| `erase(x)` | удалить сущность / массив |
| `move(x, v)`, `copy(x, v)` | сдвиг / копия на вектор; возвращают сущности |
| `rotate(x, center, axis, degrees)` | поворот |
| `scale(x, center, k)` или `scale(x, center, vec3(kx, ky, kz))` | масштаб |
| `group(x)`, `component(x, "Name")` | сгруппировать → группа / компонент |
| `explode(g)`, `make_unique(g)` | |
| `union(a, b)`, `intersect(a, b)`, `subtract(a, b)` (a минус b), `trim(a, b)` (a минус b, b остаётся), `split(a, b)`, `outer_shell([…])` | Solid Tools над солидами-группами; возвращают новые группы |
| `reverse(faces)` | развернуть грани |
| `soften(x, degrees)` | смягчить рёбра (сгиб ≤ угла); `x` — рёбра или грани |
| `material("Name", "#RRGGBB")` или `material("Name", [r, g, b])` | создать / перекрасить материал, вернуть имя |
| `paint(x, "Name")`, `paint(x, ())` | покрасить грани / группы, снять материал |
| `tag(x, "Name")` | назначить тег (создаётся при необходимости) |
| `make_parametric(g)` | сделать параметрической группой |
| `set_params(g, #{ x: 1200, y: (), z: 36, count: 3, axis: "y", gap: 100, stretch: true })` | параметры (любое подмножество ключей; `()` = «как смоделировано») |
| `params(g)` | текущие параметры (map) или `()` |

## Контекст и запросы
| Функция | Результат |
|---|---|
| `faces()`, `edges()`, `groups()`, `all()` | сущности текущего контекста |
| `entities(g)` | всё внутри группы |
| `enter(g)`, `exit()` | войти в группу / выйти (для построения внутри) |
| `selection()`, `select(x)`, `select(())` | выделение (в контексте запуска) |
| `bounds(x)` | `#{ min, max, size, center }` в мировых координатах |
| `model_bounds()` | габарит модели |
| `units()`, `materials()` | единицы модели, имена материалов |
| `all_faces()` | все грани модели, включая вложенные группы (для экспортёров) |
| `read_text(path)`, `write_text(path, text)` | чтение / запись текстового файла |

Свойства сущности: `e.kind` (`"face"`, `"edge"`, `"vertex"`, `"group"`, `"component"`, `"parametric"`), `e.valid`, `e.area` (грань, мм²), `e.length` (ребро), `e.normal` (грань), `e.center`, `e.vertices` (точки), `e.edges` (рёбра грани), `e.faces` (грани ребра / соседи грани), `e.name` (группа, можно присваивать), `e.definition`, `e.material`, `e.tag`, `e.soft`.

## Пример
```rhai
material("Oak", "#C8A064");
let top = box(vec3(0, 0, 720), 1200, 800, 30);
top.name = "Table top";
for p in [[50, 50], [1110, 50], [50, 710], [1110, 710]] {
    let leg = box(vec3(p[0], p[1], 0), 40, 40, 720);
    leg.name = "Leg";
    paint(leg, "Oak");
}
paint(top, "Oak");
let hole = cylinder(vec3(600, 400, 700), 30, 60);
subtract(top, hole);
print(bounds(groups()).size);
```

## Python
Пока Varstotas открыт, им можно управлять из Python 3. Нужен только стандартный модуль: клиент `varstotas.py` лежит в `python/` репозитория, а приложение при запуске копирует его в `~/.varstotas/python/`.

- **File → Run Script…** запускает файл `.py` через `python3` (другой интерпретатор задаётся переменной `VARSTOTAS_PYTHON`). Вывод скрипта появляется в Script Console, кнопка «Stop Python» прерывает его.
- **Из терминала:** `PYTHONPATH=~/.varstotas/python python3 my_script.py`. Адрес и токен клиент берёт из `~/.varstotas/bridge.json`.

```python
import varstotas
from varstotas import vec3, ORIGIN, X, Y, Z

m = varstotas.connect()
with m.operation("Table"):            # всё внутри — один шаг Undo; исключение откатывает
    m.material("Oak", "#C8A064")
    top = m.box(vec3(0, 0, 720), 1200, 800, 30)
    top.name = "Table top"
    m.paint(top, "Oak")
print(m.bounds(m.groups())["size"])   # vec3(1200, 800, 30)
```

- Каждая функция API Rhai — метод `m` с теми же именем и аргументами: `m.pushpull(f, 300)`, `m.rect(ORIGIN, 1000, 500)`. Свойства сущностей тоже те же: `e.area`, `e.normal`, `e.name = "…"`.
- Вместо векторов можно передавать кортежи и списки `(x, y, z)`. `vec3` поддерживает арифметику, `.length()`, `.dot()`, `.cross()`.
- Map из Rhai приходит как `dict`, `()` — как `None`. Ошибка Varstotas поднимает `varstotas.VarstotasError`.
- Вызов вне `operation()` — отдельный шаг Undo «Python».
- `m.rhai(code, **vars)` выполняет код Rhai одним вызовом; именованные аргументы становятся переменными. Так быстрее для больших циклов.
- Приложение: `m.info()` (сводка документа), `m.undo()` / `m.redo()`, `m.view("iso" | "top" | … | "zoom_extents")`, `m.camera(eye=…, target=…, parallel=True)`, `m.screenshot(path=None, width=…, height=…)` (путь к PNG), `m.save(path=None)`, `m.export(path)` (формат по расширению: stl, obj, dxf, glb, 3mf, csv, svg, pdf, png), `m.open(path)`, `m.new()`.
- Перед разрушительными действиями приложение показывает диалог «External script», и отказ поднимает ошибку. Такими считаются: сохранение поверх другого существующего файла, экспорт поверх файла, а также открытие файла или новый документ, когда есть несохранённые изменения.

Пример — `examples/scripts/bookshelf.py`.

## Мост (протокол)
Приложение слушает только `127.0.0.1`, на случайном порту. Порт и случайный токен записываются в `~/.varstotas/bridge.json` (права 0600). Отключить мост можно переменной `VARSTOTAS_NO_BRIDGE=1`.

Запрос — JSON-строка `{"id": 1, "token": "…", "method": "…", "params": {…}}`. Токен нужен в первом запросе соединения. Ответ: `{"id": 1, "result": …}` или `{"id": 1, "error": {"message": "…"}}`. Тот же JSON принимается как HTTP `POST /rpc`, токен — в теле или в заголовке `Authorization: Bearer …`. Запросы из браузера (с заголовком `Origin`) отклоняются.

| Метод | Параметры → результат |
|---|---|
| `hello` | → `{app, version, api}` |
| `eval` | `code`, `vars` (JSON), `label` → `{value, output, changed}`; сущности — `{"$entity": id, "kind"}`, векторы — `{"$vec": [x, y, z]}` (так же передаются в `vars`) |
| `begin` / `commit` / `abort` | операция (один шаг Undo); если соединение закрылось с открытой операцией, она откатывается |
| `info`, `docs` | сводка документа; этот справочник |
| `undo`, `redo`, `view`, `camera`, `screenshot` (`path`, `width`, `height`, `base64`) | |
| `save`, `export`, `open`, `new` | с подтверждением пользователя (см. выше) |

## MCP-сервер для ИИ-агентов
`~/.varstotas/python/varstotas_mcp.py` — MCP-сервер (stdio), который работает с запущенным Varstotas через мост. Подключение в Claude Code:

```
claude mcp add varstotas -- python3 ~/.varstotas/python/varstotas_mcp.py
```

Инструменты:
- `api_reference` — этот справочник;
- `model_info`;
- `run_script` — код Rhai; один шаг Undo «Agent», ошибка ничего не меняет;
- `screenshot` — PNG текущего вида;
- `set_view`;
- `undo`, `redo`;
- `save`, `export`, `open`, `new_document` — помечены как разрушительные, приложение спрашивает пользователя.
